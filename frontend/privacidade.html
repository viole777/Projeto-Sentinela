Privacidade e uso de dados

Voltar ao login
Não insira dados reais de pacientes. Este é um protótipo acadêmico para demonstração e testes. Use somente dados fictícios. Não o utilize para atendimento real, prontuários oficiais ou decisões clínicas.

Que dados usar?

Utilize nomes, documentos, contatos, endereços, históricos e informações clínicas inteiramente fictícios. Não envie informações que identifiquem uma pessoa, nem dados de saúde reais ou confidenciais.

Como os dados de demonstração são tratados?

Os registros inseridos podem ser armazenados no banco de dados conectado ao ambiente de demonstração e ficar disponíveis a pessoas que administram o projeto. Sair da conta não significa que os registros foram apagados.

O sistema contém controles de acesso e registros de auditoria como parte do protótipo, mas isso não representa uma garantia de conformidade com a LGPD nem uma certificação de segurança para dados reais.

Finalidade e limites

  • Finalidade: estudo, apresentação escolar e validação técnica com dados fictícios.
  • Não utilizar para diagnosticar, prescrever, dispensar medicamentos ou orientar atendimento real.
  • Não cadastrar pacientes, profissionais reais, senhas pessoais ou outras informações confidenciais.

Se um dado real foi inserido por engano

Interrompa novos cadastros e procure o responsável pelo projeto para avaliar a remoção do registro. Não compartilhe o dado novamente em mensagens, capturas de tela ou chamados públicos.
